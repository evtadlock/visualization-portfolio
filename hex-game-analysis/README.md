# Hex Game Analysis Visualizations

Statistical visualizations of 11x11 Hex games focusing on first move strategy, chain formation, and game outcomes.

## Key Points
- First moves are not random (chi-square test)
- Center moves dominate early openings
- Top moves produce more near-unbroken chains
- Move type affects outcomes and game length
